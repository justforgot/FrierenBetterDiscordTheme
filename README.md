# FrierenBetterDiscordTheme
Its a betterdiscord theme centered around frieren, based on the theme called "Not Another Anime Theme" by puckzxz (he did 99% of the work, all credit goes to him).
You can view his work at https://betterdiscord.app/developer/puckzxz or https://github.com/puckzxz
This theme works with Vesktop and Vencord.

To use the theme, download the .css file, go into settings and themes, then click on the "open themes folder" button and drag the file you downloaded in.
